# 🩺 HealthTrack App (Stage 1)

A simple terminal-based health tracker built in Python.  
It helps calculate BMI, log daily steps, water intake, and sleep hours — with friendly feedback.

## 💡 Features

- Input validation using `try-except`
- BMI calculation and category feedback
- Daily health metrics logging
- Motivational messages

## 📂 Files


- `healthtrack.py` – Main script

- `main.py` – Main script
- `README.md` – Project info

## 🚀 How to Run

```bash
python healthtrack.py
python main.py
